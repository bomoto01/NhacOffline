# Hướng dẫn cài đặt Tiện ích Nhạc Offline - SoundCloud Sync

Tiện ích này giúp bạn:
- Tự động phát hiện bài hát bạn đang nghe trên **SoundCloud** (`soundcloud.com`).
- Tự động đồng bộ và cào bài hát đó vào website **Nhạc Offline** mà bạn không cần phải copy/paste link thủ công.
- Có thông báo Toast nổi ngay trên giao diện SoundCloud khi bài hát được đồng bộ thành công!

---

## 🚀 Cách cài đặt vào Chrome / Cốc Cốc / Edge (Chỉ mất 15 giây):

1. Mở trình duyệt Chrome (hoặc Edge / Cốc Cốc / Brave).
2. Truy cập vào trang quản lý Tiện ích:
   - Trên Chrome / Cốc Cốc: gõ vào thanh địa chỉ: `chrome://extensions` rồi bấm Enter.
   - Trên Microsoft Edge: gõ: `edge://extensions` rồi bấm Enter.
3. Bật công tắc **"Chế độ dành cho nhà phát triển" (Developer mode)** ở góc trên bên phải màn hình.
4. Bấm vào nút **"Tải tiện ích đã giải nén" (Load unpacked)** ở góc trên bên trái.
5. Chọn thư mục:
   ```
   d:\Project\NhacOffline\extension
   ```
6. Xong! Bạn sẽ thấy biểu tượng **Nhạc Offline - SoundCloud Sync** xuất hiện trên thanh công cụ của trình duyệt.

---

## 🎧 Cách sử dụng:

1. Mở tab mới và truy cập vào **[SoundCloud](https://soundcloud.com)**.
2. Bấm nghe bất kỳ bài hát nào bạn thích.
3. Sau khoảng 3-4 giây nghe nhạc, một bảng thông báo nhỏ màu đen bo tròn sẽ hiện lên ở góc dưới màn hình:
   - `Đang đồng bộ về Nhạc Offline...`
   - `✅ Đã đồng bộ vào Nhạc Offline: [Tên bài hát]!`
4. Mở website **Nhạc Offline** (`http://localhost:5173`), bài hát vừa nghe đã có sẵn trong danh sách phát của bạn để nghe Offline thoải mái!
